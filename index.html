Cómo usar el simulador

Este entorno reproduce el flujo de trabajo de un agente en un GDS con la sintaxis de comandos de Sabre. Todo se ejecuta en tu navegador; los PNR se guardan localmente.

  1. Inicia sesión con SI*1234 (cualquier número de agente; no se piden contraseñas).
  2. Consulta disponibilidad: 115DECMIAMAD.
  3. Vende: 01Y1. Agrega nombre -PEREZ/JUAN MR, teléfono 9305-555-1234-A, ticketing 7TAW/, recibido 6JUAN.
  4. Finaliza con ER, cotiza y guarda con WPRQ, 6JUAN§ER y emite con W‡PQ1‡FCASH.

Teclas especiales: \ = ‡ (cruz de Lorena), [ = ¤ (cambio), ] = § (fin de ítem). ↑/↓ historial, Esc limpia pantalla, Alt+1..6 cambia de área.

Escribe HELP en el emulador para ver todos los temas.
